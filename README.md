# Budget simulator — Derby

Simulateur de coûts d'infrastructure à l'échelle pour Derby : projette le coût mensuel
de l'infra (VPS, stockage, comptes plateforme…) à partir d'hypothèses de volumétrie
(utilisateurs actifs, posts, images), sur la base de tarifs publics réels.

Ce n'est **pas** un suivi de dépenses réelles ni un calcul de revenus — uniquement une
projection de coûts d'infrastructure. Voir les commentaires dans `index.html` pour les
sources de chaque tarif.

Déployé via GitHub Pages sur https://budgetsimulator.derbyapp.fr
